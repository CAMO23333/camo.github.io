# CAMO anonymous project page

Static GitHub Pages website for the anonymous ICLR 2027 submission.

## Publish

Upload the contents of this directory to the root of the public repository `camo23333.github.io`, then enable GitHub Pages from the `main` branch and `/ (root)` folder.

The code button currently points to `https://github.com/CAMO23333/CAMO`.

## Anonymity

The page intentionally contains no author, affiliation, analytics, or citation metadata. Search-engine indexing is disabled during review with `noindex, nofollow`.

## Asset note

The displayed teaser was extracted from the current anonymous paper. Replace `assets/figures/teaser.png` whenever the paper figure changes.
The web version of the pipeline is stored as `assets/figures/pipeline.png` with the source margins removed.
